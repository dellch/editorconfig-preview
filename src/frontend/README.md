# EditorConfig Preview - Frontend

Vue 3 + TypeScript single-page application, built with Vite.

## Prerequisites

- Node.js `^20.19.0 || >=22.12.0` (recommended: 22 via nvm)

## Install

```sh
npm install
```

## Dev server

```sh
npm run dev
```

## Lint

Runs oxlint then ESLint with auto-fix:

```sh
npm run lint
```

## Type-check

```sh
npm run type-check
```

## Format

```sh
npm run format
```

## Build

Type-checks and produces a production bundle in `dist/`:

```sh
npm run build
```
